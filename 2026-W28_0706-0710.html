  • 主营与核心客户：集成电路封装测试，AMD核心封装供应商（全球CPU/GPU封装核心供应商）。

  • 财报趋势：7/9涨停报72.17元，龙虎榜净买入15.56亿。
  • 上涨逻辑：AI算力需求→先进封装产能紧缺→国产替代加速。
  • 风险与策略：7/10科技龙头"阴包阳"，短期回调压力大。买入条件：等回调至20日线企稳后考虑。

  • 市值：约1000亿+
  • 主营与核心客户：卫星空间段运营及相关应用服务，核心客户为政府/军队/广电/企业。
  • 护城河：国内唯一商用卫星电信运营商，排他性极强。
  • 上涨逻辑：长征十号乙首飞催化+商业航天基础设施需求。
  • 风险与策略：事件驱动型涨停，延续性待验证。买入条件：观察是否能连板确立趋势。

  • 主营与护城河：国内最大晶圆代工厂，先进制程国产替代核心。

🧠 产业逻辑深度
[ 半导体产业链 ]
• 产业链上下游：设计 → 制造（中芯国际） → 封装测试（通富微电/华天科技） → 设备（深科达/亚翔集成）。
• 技术原理：先进封装（2.5D/3D/Chiplet）是突破摩尔定律瓶颈的关键路径。
• 核心驱动力：AI算力需求爆发 → 芯片产能紧缺 → 国产替代加速。
• 受益环节：设备（国产替代率最低） > 封装测试（AMD链） > 制造（中芯国际）。

[ 商业航天 ]
• 产业链：火箭制造 → 发射服务 → 卫星运营（中国卫通） → 地面设备 → 应用。
• 核心驱动力：可回收火箭技术突破（长征十号乙首飞） → 发射成本大幅降低 → 商业航天进入规模化阶段。
• 与SpaceX对标：中国成为全球第二个掌握大运力可回收火箭技术的国家。
• 受益环节：卫星运营（中国卫通，排他性牌照） > 火箭制造 > 地面设备。

[ 创新药/CRO ]
• 产业链：研发（CRO） → 临床试验 → 上市 → 纳入医保/基药目录。
• 核心驱动力：2026版基药目录出炉，16款创新药首次入围 → 放量预期。
• 受益环节：CRO（昭衍新药） > 创新药企（常山药业/众生药业）。
